## Option 2: Text-Based Logo (5 minutes)

**Design:**
```
Black background
"SYMPHONY" in purple (#8B5CF6)
Simple geometric sans-serif font
Minimal decoration
```

**Quick creation:**

**Using Canva:**
1. Create 512x512 design
2. Set background: Black (#000000)
3. Add text: "SYMPHONY"
4. Font: Montserrat Bold or similar
5. Color: #8B5CF6 (purple)
6. Center it
7. Export PNG

**Using CSS/HTML:**
```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { margin: 0; background: #000; display: flex; align-items: center; justify-content: center; height: 512px; width: 512px; }
    .logo { font-family: 'Arial Black', sans-serif; font-size: 60px; color: #8B5CF6; font-weight: 900; }
  </style>
</head>
<body>
  <div class="logo">SYMPHONY</div>
</body>
</html>
```

Save as HTML, screenshot at 512x512, use as logo.

## Quick Creation Instructions

### PowerPoint/Keynote Method (5 min)

1. New slide, 10" x 10" (square)
2. Black background
3. Insert 🎭 emoji (or text "SYMPHONY")
4. Make it BIG (fill 60% of slide)
5. Export as PNG, 512x512
6. Done

### Screenshot Method (2 min)

1. Open any app with emoji keyboard
2. Type 🎭 emoji, zoom to full screen
3. Make background black (screenshot with black background)
4. Crop to square
5. Resize to 512x512
6. Done

### Canva Quick Link

https://www.canva.com/design/create
- Template: Logo
- Size: 512 x 512 px
- Add emoji or text
- Download PNG
